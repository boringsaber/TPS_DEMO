# TPS_DEMO
求职作品1  
作品描述:一款tps游戏，正在开发中
特点:
1.热更新:
采用xlua热更新框架，通过对比MD5文件验证服务器与本地ab包资源等是否相同。不同则通过对比文件获取服务器资源，服务器为权威。
2.人物相关控制:
采用FSM有限状态机，分层解耦人物动画，更好写动画切换之间的逻辑。
3.背包系统:
通过ScripTableobject持久化保存背包数据。背包系统目前支持选中道具及使用道具产生效果。
4.奖励系统:
杀死敌人掉落随机奖励，捡拾后加入背包。
5.任务系统:
建议任务系统，通过事件中心分发事件即观察者模式进行任务奖励分发以及目标记录。
6.各种管理器:
场景管理器，AB包资源加载管理器，游戏管理器，音频管理器等，通过泛型单例模式增强泛用性，减少代码量。
7.存档系统:
采用NewtonSoft.json将需要保存的数据转换成json序列化，再通过反序列化读取，之所以采用NewtonSoft，主要是原来的json工具无法存储一些特殊数据。同时采用无限滚动列表存储存档数据，在有大量存档的情况下降低50%性能消耗。内核是采用池化技术。
项目当前难点:
1.对象池池化子弹，会导致子弹以一种奇怪方向射出，发现是设置对象隐藏而不是销毁导致，通过每次使用子弹重置状态等解决。
